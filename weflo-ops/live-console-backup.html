01 · 경영 결정 권고

표지 · 3대 결정

이 개정판은 v4의 정책, 특허, 조달 근거를 다시 대조하고 고객 수주와 수익성에 직접 연결되지 않는 가설을 분리했다. 경영진이 결정해야 할 사업 우선순위와 영업 실행 조건을 명확히 제시한다.

결정 영역권고
국방 진입군 직접 야전 납품보다 드론 OEM과 부품사의 출하 EOL 검사부터 시작
개발 투자KAI와 로봇은 고객 자원, 예산, 구매전환이 적힌 유상 검증 전에는 개발 금지
제품 포트폴리오VAIS는 별도 매출 사업으로 관리하고 미래 통합 솔루션은 24개월 목표에서 제외
검토 기준 — 공개 원문, 특허 등록공보, 기업 제품정보, 조달·표준 문서를 기준으로 사실, 가설, 권고를 구분했다. 특허 침해, 무효, FTO, 해외 권리 행사는 별도 법률의견이 필요한 사안이다.

02 · 경영 요약 — 우선순위 P0~보류

승인 4건 · 보류 4건

v4는 기술과 시장의 가능성을 폭넓게 포착했지만 수주계획으로 쓰기에는 고객, 구매자, 예산, 가격, 반복구매의 근거가 부족했다. v5는 이를 보완해 사업을 현재 매출, 인접 확장, 유상 검증, 장기 옵션으로 다시 나눈다.

순위사업역할 · 영업 판단즉시 필요한 증거
P0기존 고객 확대와 VAIS현금 창출 우선. 설치원가, 갱신, 다거점 확장을 확인고객별 계약, 사용량, 마진, 확장 가능금액

P3로봇 액추에이터무개발 영업 정찰. 유상 검증 전 엔지니어 투입 금지샘플, 지그, 판정기준, 검증비

경영진이 지금 승인할 것

  1. 드론 OEM과 부품사 대상 생산 및 출하 품질검사 패키지의 판매 우선순위
  2. VAIS를 별도 사업 책임자와 별도 손익 기준으로 관리하는 체계
  3. 유상 Discovery와 유상 Feasibility를 거친 사업만 개발하도록 하는 투자 규율
  4. 특허법인의 제품 청구항 대응표와 FTO 검토 예산

  • 정책, 표준, 입찰 건수를 위플로 장비의 확정 수요로 환산하는 매출계획
  • 고객 자원과 구매전환 조건이 없는 무상 맞춤개발
  • 비식별 특징값과 모델을 위플로가 자동으로 재사용할 수 있다는 데이터 전략

03 · 사실 검증과 필수 정정

판정 10건 · 교체 문장 4개

외부 사실은 확인 수준을 구분했다. 정책, 특허, 표준의 존재는 공개기록으로 확인할 수 있지만 구매 의향, 원가, 마진, 보안 승인, 반복구매는 내부 증빙과 고객 확인이 필요하다.

v4 주장 또는 논리판정v5 반영 문구
등록특허 25건확인국내 등록 재고는 확인. 독점성, 해외 권리, 침해 가능성으로 확대 해석하지 않음
자동차, EV, 배터리 특허 5건정정자동차와 전기차 검사 4건, 비행체 배터리 점검 1건으로 분류
미국의 외산 드론 수입금지정정신규 외산 UAS와 핵심부품 모델의 장비인증 제한. 전면 수입금지 아님
미국 현지 생산 필수정정공급망 재편 신호. OEM별 품질공정 발주와 현지 요건 확인 필요
국방 드론 6만 대시장 신호정책 계획이지 위플로 검사장비의 확정 구매계획은 아님
상용드론 군용인증체계정정기존 시행 제도가 아니라 국방부가 구축을 추진하는 계획

CBM 20에서 30퍼센트 비용절감근거 약함현장별 기대효과 또는 가설로만 표현
현대차 컨소시엄 VAIS 실증확인하되 제한실증은 다거점 반복매출과 별도로 검증
국방 데이터 재사용계약 필요원시, 가공, 모델, 임계값, 로그별 권리와 반출 규칙 분리

보고서에서 바로 교체할 문장

외부 자료로 검증한 정책, 특허, 공고는 출처별로 확인했다. 다만 실제 구매 의향, 설치기반, 원가와 마진, 보안 승인, 데이터 사용권, 반복구매 가능성은 내부 증빙과 고객 확인 전까지 사업 가설로 관리한다.
FCC 조치는 북미 신규 드론 제조와 공급망 재편 가능성을 높이는 시장 신호다. 위플로의 기회는 미국 현지 생산 의무라는 전제가 아니라, 북미 OEM이 신규 품질검사 공정을 실제로 설계하고 발주하는지에 달려 있다.
국방 드론 확대 정책과 드론 표준 제정은 시장 신호다. 위플로는 기체 수량을 매출로 환산하지 않고 반복 점검 대상 기체, 검사책임자, 검사시간, 품질비용, 예산, 조달경로가 확인된 사업만 영업기회로 관리한다.
위플로는 군의 비행 가능 여부를 대신 판정하는 장비가 아니라 생산과 정비 과정의 검사시간을 줄이고 이상징후와 검사이력을 표준화해 품질책임자와 정비조직의 판단을 지원하는 솔루션이다.

국방 드론의 국산화, 표준화, 정비 데이터화 방향은 위플로에 유리한 시장 신호다. 그러나 이를 곧바로 야전 MRO 장비 구매수요로 연결하면 안 된다. 실제 첫 수주는 군 납품 드론 OEM과 부품사의 생산, 출하 품질검사에서 나올 가능성이 높다.

국방 표준화와 조달의 원칙

  • 표준 의견수렴에는 위플로 고유 구조를 넣지 않는다. 교정이력, 시험조건, 로그 무결성, 추적성, 성능기반 합격기준처럼 다수 공급자가 충족할 수 있는 요구조건을 제안한다.
  • 공고, 전시회, 정책은 시장 신호로만 관리한다. 입찰번호, 예산, 적격요건, 실제 검사 요구, 수주사, 고객 담당자, 역할, Bid 또는 No bid 결정을 표로 남긴다.
  • 국방 데이터는 기본값을 고객망 내 처리와 외부 반출 없음으로 둔다. 외부 재사용은 계약과 보안 승인 이후의 선택사항이다.

KAI 계정계획 — KAI에는 전사 드론 정비 플랫폼을 제안하지 않는다. 특정 기체 또는 특정 자산 1개를 선택해 검사시간, 불량 재현율, 반복성, 오탐과 미탐, 교정주기, 환경 한계를 검증한다. 공급사 등록과 품질, 보안, 구매 절차를 병행한다.

확인 대상확인 질문
기술사용자어떤 생산라인, 기체, 지상시험 자산에서 어떤 검사를 반복하는가
