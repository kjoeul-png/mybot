# mybot — Claude 텔레그램 봇 + SRT 빈좌석 모니터링

## 기능

- 💬 Claude AI와 자유 대화 / 파일 분석 / 검색 요약
- 🚄 **SRT 빈좌석 모니터링**: 원하는 시간대에 빈좌석이 나올 때까지 자동 조회 →
  발견 즉시 **예약(좌석 선점)** → 텔레그램으로 "💳 결제할까요?" 버튼 전송

## SRT 모니터링 사용법

```
/srt 출발역 도착역 날짜 시작시각 종료시각
```

예시 — 9월 5일 14:00~18:00 사이 수서→부산 열차 모니터링:

```
/srt 수서 부산 20260905 1400 1800
```

- 빈좌석이 나오면 가장 빠른 열차를 즉시 선점하고 알림을 보냅니다.
- **💳 결제하기** 버튼: 등록된 카드로 자동 결제 (카드 미등록 시 SRT 앱 결제 안내)
- **❌ 예약취소** 버튼: 선점한 좌석 취소
- ⚠️ 결제하지 않으면 약 10분 후 예약이 자동 취소되니 알림이 오면 바로 확인하세요.

기타 명령어:

| 명령어 | 설명 |
|---|---|
| `/srt_status` | 모니터링 상태 확인 |
| `/srt_stop` | 모니터링 중단 |

## 환경변수 설정

### 필수

| 변수 | 설명 |
|---|---|
| `TELEGRAM_TOKEN` | 텔레그램 봇 토큰 |
| `CLAUDE_API_KEY` | Claude API 키 |
| `SRT_ID` | SRT 멤버십 번호 (또는 이메일/전화번호) |
| `SRT_PW` | SRT 비밀번호 |

### 권장

| 변수 | 설명 |
|---|---|
| `SRT_ALLOWED_USER_ID` | 이 텔레그램 유저 ID만 SRT 기능 사용 가능 (본인 계정 보호) |
| `SRT_CHECK_INTERVAL` | 조회 간격(초), 기본 10초 — 너무 짧게 설정하지 마세요 |

### 카드 자동결제 (선택)

설정하지 않으면 예약 후 SRT 앱에서 직접 결제하면 됩니다.

| 변수 | 설명 |
|---|---|
| `SRT_CARD_NUMBER` | 카드번호 (숫자만) |
| `SRT_CARD_PASSWORD` | 카드 비밀번호 앞 2자리 |
| `SRT_CARD_BIRTHDAY` | 생년월일 6자리 (법인카드는 사업자번호 10자리) |
| `SRT_CARD_EXPIRE` | 유효기간 YYMM |

> ⚠️ 카드 정보는 코드에 적지 말고 반드시 환경변수(Render 대시보드의 Environment)로만 설정하세요.

## 실행

```bash
pip install -r requirements.txt
python main.py
```

- `WEBHOOK_URL` 환경변수가 있으면 Webhook 모드(Render.com 배포용), 없으면 Polling 모드로 실행됩니다.

## 참고

- SRT 조회/예약은 [SRTrain](https://github.com/ryanking13/SRT) 라이브러리를 사용합니다.
- 개인 계정으로 본인 승차권을 예매하는 용도로만 사용하세요.
